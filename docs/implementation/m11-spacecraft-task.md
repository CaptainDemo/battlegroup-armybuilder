## 目标和当前基线

实现模块计划中的 M11：从当前编辑草稿和同一次 Evaluation 生成完整军表打印投影、预览及浏览器打印入口，允许用户通过浏览器另存 PDF。先阅读 AGENTS.md、模块计划 M11、架构的打印及版本边界、开发说明，以及当前 RosterWorkspace、领域契约和已交付的单位资料。

当前 M01–M10、首批 Sites 部署及车辆／武器详情已经交付。工作树只有既有未跟踪 AGENTS.md，本任务契约是主 Agent 新增的交接记录。当前数据为 Classic 苏联 V4.1 的精确目录 1.0.0、1.1.0，另有 `soviet-afv/1` 和 `draft6-weapons/1` 只读资料包。已有 344 项单测、18 项系统 Chrome 回归通过。发布数据和规则均保持原样，Classic 规则问题由用户后续单独反馈，不在本轮扩展核对。

## 必须实现的行为

1. 编辑器中提供清晰可达的打印预览／打印入口，桌面及小屏可操作。通过浏览器打印输出 PDF，不新增专用 PDF 引擎或业务后端。无有效草稿时提供明确状态，不打印其他军表或空白占位。
2. 打印读取当前内存草稿，即使尚未保存、保存失败或军表违规也可使用。不得为打印强制保存或改变玩家选择。打印中保留违规和检查不完整状态，不以阻断打印替代反馈。
3. 投影使用同一份 RosterDocument、精确目录 release 和 Evaluation，核对 rosterId、inputRevision、catalog/version 身份。费用、组成和问题使用该评估快照，不在展示层重新计算规则或另走费用公式。拒绝错配／过期快照，不把上一次军表的评估印到当前草稿。
4. 打印标题、规则体系／军表、预算及规模／已选场景等设置、Points／BR、规则／目录／文档版本和玩家备注。已知小计和最终总额区分；未知、不适用及已知零保持各自含义。覆盖不完整时不宣称完整合法。
5. 包含所有购买、固定组成、连内子排、外挂附件、实际配装、作用目标、训练等级及选择备注。按玩家军表层级及稳定身份关联，正确呈现挂在固定子排上的附件，不按名字或数组位置猜测归属。编辑器折叠／当前选中哪一排均不影响内容完整性。
6. 固定子排仍包含在父编制费用内，不重复计费；选项名称、成员目标、逐目标计费次数和实际费用可读，购买层级与纯组成层级分开。合计与编辑器同一次快照一致。未选择的选项不得作为已装备输出。
7. 本轮以完整可上桌军表为重点，车辆和步兵的区分沿用既有实现。若输出车辆／武器速查，复用已核实资料及目标解析，打印资料包版本、来源和缺口，不复制一套独立数据或引入新的规则解释。无需将编辑器全部详情控件原样打印。
8. 打印视图隐藏导航、购买按钮、编辑控件及与纸面无关的工具栏。采用 A4 的合理纸边距、黑白可读的层级／表格和分页样式。长名称、长备注、长选项目标均换行，避免横向裁切。允许跨页拆分大型连／表格，不以整段 break-inside:avoid 导致超高块被截断；保留标题、必要表头及可读总计。
9. 玩家名称和备注等始终按文本渲染，不能作为 HTML 注入打印文档。预览／返回编辑器不清空草稿、撤销历史或保存状态。若打印视图冻结快照，明确预览时机并允许关闭后再打开取得最新草稿，不能静默使用过期结果。
