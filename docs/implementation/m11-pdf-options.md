# M11 PDF 选项：附加载具与武器数据

日期为 2026-11-10。本次由主 Agent 直接实现，未调用外部模型。保留此前 M11 未提交的实现和验收记录，不修改 Classic 数据、规则、费用公式或存档格式。

## 使用与行为

打开编辑器的 Print / PDF，在 PDF options 中勾选 **Append vehicle and weapon data**。
默认不勾选；勾选后在军表末尾从新页开始附上当前军表的载具和武器数据，取消后移除
附录。选项刷新快照时保持，关闭预览后重新打开恢复默认，不写入军表或影响保存。

载具按精确 profile 身份和配装配置合并，显示数量、移动、装甲、体型、NBC、两栖、
夜视、机枪安装、特殊规则、主武器／弹药的距离表及来源。目标升级配置单独展示，
已被替换的 ATGM 行不再输出。步兵携带的武器和额外车载系统按稳定武器 ID 去重，
只附一份属性表；各载具原卡的主炮／弹药表保留在对应载具内。

使用同一次评估和精确目录绑定，不遍历整套目录补入未购买单位。资料缺失时仍显示
载具名称、数量及未核实提示，缺失武器和未分类条目保留列表，不用相近型号填值。
已有已知零、不适用、来源差异及可选导弹解释均保持不变。

## 实现边界

- `PrintPreview.tsx` 增加局部 `PrintOptions.includeUnitData`，预览控件位于纸面外。
- `printProjection.ts` 的参考投影携带精确绑定的资料卡、profile 身份和已选额外武器，
  继续只读当前快照，不重新评估、计价或改变选择。
- `PrintUnitDataAppendix.tsx` 排版附录，复用详情栏的 `CombatCard`／`WeaponDetails`。
  原详情面板行为不变；附录中的来源说明始终展开，没有折叠造成的内容遗漏。
- A4 数据表使用 8pt 字号并保留完整距离栏。每张有界资料卡尽量保持同页，主军表的
  大编制仍可跨页，不把整军表设为禁止分页。
