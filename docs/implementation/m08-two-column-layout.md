# M08 两栏布局改版

日期：2026-11-03。按用户已确定的方案调整Web交互：军表、排及排内附件始终属于左栏；右栏在添加候选与已购单位详情之间切换，不因附件产生第三栏。没有改动目录、领域命令、计价或Classic规则，也没有推进M09。

## 本版行为

- 左栏按正式目录已开放分类显示购买实例，分类底部提供添加编制；可购买附件的排下显示已购附件及添加排内支援。每个已购实例都有独立删除按钮，删除未选单位不会切换正在查看的详情；删除父排沿用命令的级联删除及撤销。
- 点击分类添加，仅列出该分类的顶层条目；点击排内支援，仅列出该父实例可购的附件，资格及名额原因沿用规则引擎。右栏显示目标名称／序号，不根据后来选中的附件猜测父排。
- 添加后保留候选列表以便连续购买；点击左栏单位，或选择完成添加，则切换到所选单位详情。搜索无结果有提示。多个同名排的详情带对应显示序号，数据引用仍使用稳定实例ID。
- 删除正在添加附件的父排时，清除失效目标，不把附件添加到其他排。新增／打开军表重置添加上下文；撤销仍按原有会话历史生成新revision。
- 桌面只有军表／操作两个列区域，右栏随页面滚动保持可见，长详情可单独滚动；切换上下文回到内容顶部。小屏只有军表／操作两个面板入口，附件仍嵌套在军表树内。
- 原有预算、BR、计价明细、检查覆盖和问题定位继续使用同一Evaluation。当前页面会话仍不具备刷新恢复功能。
