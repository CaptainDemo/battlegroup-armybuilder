## 交付

- 我的军表：同一页面会话内创建多份、打开、丢弃；支持空军表和398 Points / 23 BR示例。规则／军表入口明确只开放Classic苏联V4.1，使用精确目录1.0.0及其已验证指纹。
- 编辑器：六个顶层条目、四个合法父编制附件，搜索、分类、价格和不可购原因；购买实例层级独立于目录分类。
- 详情：选项、稳定成员目标、当前派生组成、费用明细及PDF来源页；未知战斗属性有明确提示，没有用0填补。
- 同一Evaluation显示Points、BR、预算余量、覆盖、支援账本、Officer／Scout统计及问题。没有错误也只表示已覆盖检查通过；不宣称完整军表合法。
- 通过M05命令新增、配置、复制子树及级联删除；设置表单一次提交是一个原子批量。每份军表独立维护最多50步撤销／重做，撤销也生成新编辑revision；只接受当前revision的评估结果。
- 桌面三栏，小屏按目录／军表／详情切换。问题可选中对应实例并打开军表面板；预算问题聚焦预算输入。
- 目录加载失败时禁用创建并提供重试。导航到Roadmap再返回保留会话；刷新或关闭清空。页面显著显示未保存，不把内存状态称作本地存储。
