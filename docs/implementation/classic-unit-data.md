# Classic 单位资料首批接入

日期为 2026-11-09。右侧详情栏新增 Unit data。车辆展示独立属性，步兵及武器组展示其携带武器的属性。M11 打印及部署更新不包含在本次修改中。

## 来源及范围

来源为本地 `references/BGCW Soviet AFV data cards.pdf`，SHA-256 为 `80e560ea58f716ca1b49075f1635d2ed557209c18bc607fe7c6902875fb8cbd1`。已逐页查看 9 页原图，核对本批使用的 51 张卡片，逐张保留 PDF 页码及卡片位置。M01 的 fingerprinted-only 记录保留其原始历史含义。

资料包 `packages/catalogs/classic-coldwar/reference/soviet-afv-v1.json` 的版本为 `soviet-afv/1`。当前目录 1.1.0 明确关联 52 个 profile，旧目录 1.0.0 明确关联 7 个 profile。BMP-1 和 BMP-1AA 对应原卡标题中明确列出的同一车辆卡。所有关联都绑定 Classic 的完整目录身份及 profile ID，不按名称推断，不借用 AirLand 或 NORTHAG 数据。

显示内容包括公路／越野移动、F/S/R/T 装甲、体型、NBC、两栖、夜视、机枪安装方式、卡片特殊规则，以及逐种弹药的 HE、代际和八个距离栏数值。距离单位为英寸，距离栏标签按原卡保留，包括原有的 0–5 与 0–10。已知装甲 0 显示为 0；原卡横线显示为不适用，不转换成数值 0。

武器来源为 `references/Unofficial Battlegroup CW Rules. - Draft 6pdf.pdf`，SHA-256 为 `56595a4c83a35e6acf5242800361285381a16b0f44846331c7c26f2c5bda0b1b`。已核对原页 8、9、15、20、21、22、23、31、50。`reference/draft6-weapons-v1.json` 的版本为 `draft6-weapons/1`，含 33 条 Classic 专属武器记录，覆盖轻武器、RPG／LAW、AGS-17、迫击炮、喷火器、热压火箭、苏联 ATGM 和 SAM。

当前目录全部 125 个 profile 都有明确展示分类：86 个车辆、29 个携带武器／班组装备关联、7 个人员／编制容器／非武器装备、3 个尚未核实的武器。步兵不展示或要求独立装甲资料。RPK-74 按 p.20 明确归入 LMG，RoF 为 3；SVD Marksman 保留 p.31 限制，不套用带观察员的狙击手延长射程。AK-74 班组装备关联只显示每名射手的属性，不由总人数推算步枪数或总火力。

ATGM 独立展示代际、背焰、串联、可靠性、HE 效果及穿甲距离表；SAM 独立展示系统／雷达类型、攻击修正和伤害。SA-7 的攻击修正 0 保留为已知零，不生成未提供的穿甲值或射程。通用武器表使用 5–10 距离栏，车辆卡原有 0–10 标签保持各自来源。

## 版本及评估边界

该资料包是独立版本的只读参考数据，随 Web 构建发布。通过 Classic 专属 schema 校验后，按精确目录身份和 profile ID 查找。原目录 1.0.0／1.1.0 的字节、指纹及其中的 unknown stats 均保留。旧存档能显示补充资料，同时保持原有的选择、版本、Points／BR 和校验覆盖。

界面从当前评估快照的组成子树读取实际车型、武器和数量。选择连内固定排时仅显示对应子树；车型、PKM、RPG、SA-14 等替换后显示当前资料。Konkurs／Svir 根据已评估的目标标签关联武器，按目标配置分别合并车辆，不把单车升级扩散到同型车辆。明确选择的导弹升级会隐藏该车原卡中已被替换的 ATGM 行，并显示 Draft 6 的对应数据。资料卡不会参与计价、规则检查或存档写入。

## 明确保留的缺口

- 通用卡车、直升机和缺少对应卡片的车辆变型保持未核实。指挥型不直接套用普通车型。爆破包、100mm T-12／MT-12、125mm Sprut-B 的武器属性仍待对应来源核对。
- 人员、观察员、装填手、编制容器及非武器装备不生成虚构的车辆属性；没有记录的个人武器不由人员数量推断。
- T-72B1 卡片包含可选 Svir，不自动列为已装备。已选择 Svir 时展示导弹资料，但 T-72B 车体属性仍保持未核实。T-62MB 的 Bastion 模型替换能展示已知导弹资料，其未关联的车体卡仍保持未核实。
- 车辆卡与通用武器表的数值可能不同。例如 BMP-1P 卡的 Spigot 可在 10–20 距离栏使用，Draft 6 p.15 Fagot 表在此栏为横线；通用 Refleks／Svir 的串联列为 No，而部分车辆卡标 Tandem。保留各自来源，不以现实装备知识或另一个表自动覆盖。
- 原卡有疑似错误时保留定位及说明，包括 T-80BV 未列 Reactive Armour、SA-8／SA-11 的车辆行、PMM-2 的 GSP 行，以及 Spandrel 的导弹编号。未以现实装备知识改写原始数值。
- 来源卡中的特殊规则仅作资料展示，不扩大静态合法性检查范围，也不实现战斗过程。
