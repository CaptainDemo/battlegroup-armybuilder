# 苏联装甲师 V4.1 编制验收

2026-11-04。Classic Cold War 的默认目录升级至 1.1.0。目录索引同时保留 1.0.0 的原路径和 SHA-256。应用按精确版本读取目录，新建军表采用 1.1.0。

## 数据范围

按 SOV V4.1 PDF 第 1–15 页的购买条目及选项录入。151 个购买记录包括 120 个顶层条目和 31 个附件购买上下文，另有 203 个配装选项与 125 个 profile。覆盖 HQ、摩托化步兵、坦克、侦察、专业支援、炮兵、工兵、后勤、额外火力支援与防御设施。固定子排计入连的基础价格，界面将子排及其附件嵌套在左侧军表中。

连内附件按连实例及固定排的成员路径定位。排内附件槽与全军支援额度分别计算，第二 Fire Support Section 需要同排先有第一 Section 并占用一个排内槽。全体 BMP 升级按作用域内的实际匹配车辆计价，包括已购买附件的运输车。

- A05 的整次升级占一个 Restricted 或对应 Unique 名额。T-62 连最多选三辆改装 Bastion，每辆单独付费，合计占一个 Unique 名额。
- A06 的 SAM Section 在每个连内最多由一个排购买。升级为 SA-14 后仍占用该名额。所属连的排内 SA-7 升级与该 Section 互斥。
- BMP-1 空运转换保留步兵，移除购买范围内的 BMP 运输，按独立排或连加入一架或三架 Mi-8。FHQ 的指挥坦克选项按原表替换三人指挥组，保留单独列出的运输车。

火力、飞机和直升机的对局随机表与到场处理，以及第 16–21 页的战斗资料仍在覆盖范围之外。未核实的战斗属性标为未知。TOC 和 EW 的部分运输型号沿用原表的并列描述，目前由一个 profile 表示。应用继续报告规则覆盖不完整。

## 验证

- 281 项 Vitest 检查通过。新增 61 项编制检查，包含独立列出的基础价格断言，以及 Restricted／Unique、局部附件、空运、PT-76、防御设施资格和 ToT 等边界。
- 类型检查、生产构建和 6 项 Chrome 回归通过。构建检查两版目录的索引、指纹和公开资源清单。
- Chrome 编辑流程确认原示例仍为 398 Points／23 BR。BMP-1 连基础为 275／25，三个固定排显示在军表中。为第一排购买两段火力支援和 SAM 并换装 SA-14 后，第二排的 SAM 购买被阻止，仍可购买自己的火力支援。第一排的 BMP-1P 选项命中六辆，军表达到 420／29。删除第二段火力支援后为 395／28，撤销恢复 420／29。
- Chrome 为 T-62 连选择全连 T-62M、三辆 Bastion 和 Regular，连价增加 455 Points／30 BR。防御设施购买随攻守身份变化。在 360px 视口下，固定排仍位于军表面板，点击排内添加切换到操作面板，页面无横向溢出。
