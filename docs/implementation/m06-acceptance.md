# M06 通用评估、费用与资源

日期：2026-11-03。入口`evaluateRoster(document, catalog)`；目录须已通过M04的schema／关系检查。core不包含Classic阈值、等级枚举或具体单位记录；输入一致产生相同快照，输入不被修改。

## 实现

- 先检查文档形状、结构与精确引用；结构损坏不输出完整费用，保持coverage不完整。
- 每份购买产生唯一基础费用行，固定成员不再计价；附属购买保留自己的费用归属。支持一次／每目标、数量乘数、免费替换、负差额、已知零及BR变化。未知或不适用费用只产生已知小计，不补0。
- scope-selector按当前目录与购买树重建目标，包含已购附件；每个拥有者／成员路径只处理一次，不依赖过时的显式all清单。非递归selector只处理本购买的直接成员；递归selector覆盖静态后代和附件。个体可配装成员需按稳定节点分别录入；profile位于组成根的单体替换使用whole-selection选项。
- 同一all重复选择有明确问题且不重复收费。父all与局部附件的相同型号替换、单模型价格一致时共享一次费用；部分重叠或价格不一致会报告问题并把该费用标为未知，不猜测折算。
- 派生组成支持型号替换、训练变化、标签和声明式成员新增；派生节点与原目录节点类型分开。新增稳定ID碰撞会报错。
- 按选项组作用域检查组上限、逐项上限、前置和互斥；未知上限保留覆盖缺口。无需为单元测试返回M01字面期望值。
- 资源池按产生者、资源类型及作用域独立；带类别资格的容量采用增广匹配，避免先把灵活额度分给错误消费者而造成假短缺。army、parent-formation、formation-member不混用，豁免消费不推导额外授予。
- 输出同一份组成、费用行、总额完整性、额度、问题及覆盖，携带inputRevision。M06的game-rules覆盖明确not-implemented，无错误也不会称完整合法。
